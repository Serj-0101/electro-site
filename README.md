# ГЕРМАН — сайт электромонтажной компании

Многостраничный сайт компании «ГЕРМАН» (Майкоп, Республика Адыгея).
Монтаж электропроводки, электрощитовых, освещения и уличного освещения.

## Стиль
Дизайн в атмосфере [activetheory.net](https://activetheory.net): тёмная тема,
WebGL-частицы «живой электрической энергии» в Hero, прелоадер со счётчиком,
кастомный курсор, магнитные кнопки, полноэкранное меню.

### 🔜 Заявки с формы → мессенджер MAX (ОТЛОЖЕНО — сделать при переезде на Netlify)
**Схема:** форма на сайте → `POST https://electro-sit.netlify.app/.netlify/functions/lead`
→ Netlify Function → Bot API MAX (`POST https://platform-api2.max.ru/messages?chat_id=…`)
→ сообщение владельцу в MAX: «⚡ Новая заявка: имя, телефон, задача».

**Почему нужен прокси (Netlify Function):** токен бота нельзя хранить в коде
статического сайта — посетители увидят его в исходниках. Токен живёт в
переменных окружения Netlify.

**Сработает и пока сайт на GitHub Pages** — запрос идёт на абсолютный адрес
функции, CORS разрешается заголовком `Access-Control-Allow-Origin: *` в функции.
Зависимость: зеркало на Netlify должно быть живым (сейчас деплоится автоматом).

**Шаги при реализации:**
1. Создать бота в MAX (платформа «MAX для бизнеса», раздел «Чат-боты») → получить `access_token`
2. Написать боту любое сообщение со своего аккаунта — открыть диалог
   (без этого бот писать первым не может)
3. Получить `chat_id` — одноразовый python-скрипт: `GET /updates` у Bot API,
   взять chat_id первого сообщения
4. Написать `netlify/functions/lead.js` + `netlify.toml`:
   - CORS `*`, honeypot-поле против спама, базовые лимиты
   - env-переменные: `MAX_BOT_TOKEN`, `MAX_CHAT_ID` (задать в Netlify UI:
     Site configuration → Environment variables)
   - ⚠️ токен передавать заголовком `Authorization: <token>` (query-параметры
     API больше не поддерживает), домен `platform-api2.max.ru` (не `platform-api.max.ru`)
5. `js/main.js`: форма отправляет JSON `{name, phone, task}` на функцию;
   состояния «отправляется / успех / ошибка — позвоните нам»
6. Тест: заявка с сайта на GitHub Pages → сообщение приходит в MAX

**План Б:** если Bot API MAX упрётся (TLS/сертификат Минцифры на стороне
сервера и т.п.) — тот же самый прокси переключить на Telegram Bot API.
