# Сайт электромонтажной компании

Многостраничный сайт для компании по монтажу электропроводки и электрооборудования.

## Структура
```
├── index.html          # Главная страница
├── pages/              # Внутренние страницы
├── css/                # Стили
├── js/                 # Скрипты
├── img/                # Изображения
```

## Локальный запуск
Открыть `index.html` через Live Server (VS Code) или просто двойным кликом.

## Технологии
- HTML5, CSS3, vanilla JS
- Хостинг: GitHub Pages
