# ГЕРМАН — сайт электромонтажной компании

Многостраничный сайт компании «ГЕРМАН» (Майкоп, Республика Адыгея).
Монтаж электропроводки, электрощитовых, освещения и уличного освещения.

## Стиль
Дизайн в атмосфере [activetheory.net](https://activetheory.net): тёмная тема,
WebGL-частицы «живой электрической энергии» в Hero, прелоадер со счётчиком,
кастомный курсор, магнитные кнопки, полноэкранное меню.

## Структура
```
├── index.html          # Главная страница
├── pages/              # Внутренние страницы (этап 4)
├── css/style.css       # Дизайн-система
├── js/webgl-hero.js    # WebGL-сцена Hero (Three.js)
├── js/main.js          # Интерактив (прелоадер, курсор, меню, формы)
├── img/                # Изображения
```
